Key Concepts

Moats in AI-Native World
Data · trust · distribution · decision traces. Services → software as vibe-coding lowers the barrier. Strangler Fig pattern for migration.
Intent Economy
From attention to intent. Agent-to-agent: buyer → MCP → seller. GEO (llms.txt, JSON-LD). Verification gap is the new ad inventory.
Process Audit
67% see pilot results, 10% scale. Method: 15-20 interviews, prioritization formula, cost/revenue/enabler map. 80+ initiatives from a 200-person fintech.
90-Day Plan
AI Champion (KPI'd role) + AI Operating Officer. Budget $120-290/mo. Month-1-2-3 plan. Day-90 checklist.
Flattened Org
From functions to 3 blocks (R&D, GTM, G&A). Human: Chief Accountability Officer, System Architects, Relationship Experts, Validators. AI: reasoning + action agents.
Sales L1–L5
Levels of sales autonomy (like self-driving cars). Inbound qualification + outbound prospecting as the first automated pipelines.
Shared Workspace
Single tree for humans and agents. CursorRules/Agents.md as hub. Tool-agnostic principles — migrate Cursor → Claude Code without rewriting.
Process as Product
Every process has a product owner, backlog, OKRs, unit economics. Data flywheel: executions → labeled data → better evals → better process.
